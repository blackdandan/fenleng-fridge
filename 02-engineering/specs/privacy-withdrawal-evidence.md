# App 统一隐私撤回阶段证据

本项执行已批准 WP03 的统一隐私撤回要求，并保护微信授权等异步身份流程。不是账号注销，也不声称删除平台已经受理的数据或撤销已发给外部微信客户端的授权请求。

设置 → 隐私政策仍使用随包离线原生 WebView。只有已同意的隐私正文尾部添加当前语言的撤回链接；协议、同意前阅读不提供该动作。原生阅读器拦截唯一 URI 并返回 Flutter，再显示带 16px 外边距的确认对话框。取消不修改同意记录；确认后停止本地提醒、遥测和在线身份，清理活动会话后返回中国渠道同意页。库存、照片、语言和外观设置保留。

原生 `privacy.revoke` 将移除同意记录和持久写入 withdrawalPending 合并。清理失败显示独立重试页，当前进程不恢复 SDK 或绕过同意；pending 已成功落盘时，重启先恢复 pending 清理，再决定是否进入业务。如果首次原生写盘本身失败，则必须重试，不能保证进程被强杀后记住一次从未写盘成功的操作。只有全部清理成功才调用 privacy.finishRevoke。Android/iOS/Harmony 均有对应原生源码；后两端不冒称设备验收。

身份存储先封闭旧实例并等候已排队写入；迟到的授权回调不能交换会话，迟到的 SDK 写入不能恢复凭据，旧实例的清理也不能覆盖重新同意后的新凭据。停止在线服务不发送新的 logout HTTP。主动会话文件写为 `{}`，删除该文件确切的 `.pending` 暂存；不宣称安全擦除，不处理历史损坏诊断副本。
