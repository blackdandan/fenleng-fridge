## 工作包与依赖

### WP01 工程与能力基线

建立 Flutter FVM/Melos 多包，Day 1 Android/iOS/ohos；Taro/pnpm workspace（domain/application/platform-contracts/adapters/api-client/ui-kit）；官网独立静态构建。固定版本与源码来源，工程根配置不混入其他项目。原型保留为参考。

验收：基线预检、依赖解析、架构边界检查、三端标识；记录 SDK/NDK/Java/Node/微信/鸿蒙/iOS 环境能力。Android 签名预览后按已获专项授权生成、登记并入 Vault，无秘密输出，不轮换。

### WP02 本地领域、持久化与提醒周期

实现照片记录/稳定编号、区域、时间和间隔、四种绝对剩余状态、历史/删除/恢复/撤销；不上传照片或库存。不设示例库存作为正式首装状态。App 与微信共用行为契约与测试场景，代码按语言分别实现，不跨语言强行复用。

提醒：本地自然日合并、同周期去重、原始数/待处理数分离、部分/全部处理、改期与旧周期隔离、移动/间隔编辑不错误解除待处理、恢复新周期、撤销/重启重算。

验收：边界时间、跨日/同日增量、持久化失败/恢复、未选记录不变、历史恢复不激活旧周期、图片文件持久化/清理及微信配额错误。

### WP03 统一 UI、离线协议与国际化

按已验收稿实现首页柜体、空状态、区域记录、整理、通知列表/完成态、详情、历史、设置、法律和反馈。相机独立页面；真正弹窗左右至少16px；相机权限解释顶部16px。无底部导航。设置尾部协议/隐私/反馈/备案查询。

中国首进同意、两份随包协议、拒绝/阅读返回/记录失败/重试/版本变更，三端 DeferredPluginRegistrant；global 首帧不出现中国门禁。统一隐私撤回停止网络采集并清队列，不额外添加分析开关。20语言实际译文、语言切换持久化、RTL/长文本/大字体/iPad 基础限宽；语义 Token 集中管理。

验收：布局测试与逐屏截图对照；首装空冰箱；无同意不初始化 SDK/权限/库存；china/global 首帧检查；语言键完整与变量一致。

### WP04 原生拍摄、相册与系统通知

相机连续拍摄入库、区域切换只影响后续、相册多选/错误/权限拒绝/永久拒绝/系统设置返回、重拍替换；三端功能适配。按日期合并本地通知、点击进入对应周期未处理项、Android 通知权限与重启调度、iOS/HarmonyOS 对应生命周期。

验收：对应平台可运行测试、权限顺序、并发防重、无权限替代入口、真实图片留存；模拟不充当原生证据。未连接设备时继续构建与适配测试，设备验收明确交接。

### WP05 Shared Platform 身份、反馈与埋点

重新锁定真实合同；游客会话创建如缺失则在平台与 SDK 补齐。App 可选微信登录；小程序 code 换平台会话；Apple 平台同等级 Apple 登录。正确处理取消、未安装、受限、超时和迟到回调，配置缺失给出本地化状态，不伪造令牌或成功。库存保留本机，不因登录隐式同步/删除。

反馈使用官方 SDK、认证与幂等键，失败保留草稿/重试，真实响应才成功。遥测官方 SDK 单一入口，事件白名单与枚举属性、同意门禁、公共上下文、100队列/50批量及有界重试；不记录照片、食材、库存ID、反馈正文或凭据。

验收：上游合同与幂等/并发测试、认证/应用隔离、成功/失败/取消、未知事件/敏感键拒绝与撤回清队列。上游变更保留其他未提交修改，登记 TD/知识影响；本轮不擅自部署平台。

### WP06 微信订阅消息

使用平台既有机制；确需扩展时在已授权 Shared Platform/SDK 范围补齐，禁止本产品另建服务器。记录微信一次性许可等平台限制，站内闭环始终独立可用。
