01 / 拍摄

一张照片，一条记录。

不用填写名称和数量。选好储存区域，可连续拍摄，也能从相册一次加入多张照片。

02 / 整理食材

还剩多少，你来确认。

每次整理，只确认你看过的食材；没了就移到历史，也可以撤销。

03 / 检查提醒

到了时间，提醒检查。

按记录的检查间隔提醒，处理后开启下一周期。未处理的仍留在待检查列表。

照片与库存仅存本机

记录轻一点，边界说清楚。

照片、库存和历史保存在本机。无需账号密码，不做食材识别或云同步。

游客身份、反馈和必要产品分析通过 Shared Platform 接入中，不因此上传食材照片或库存。

卸载或清除数据可能丢失本机记录；提醒不构成食品安全结论。
