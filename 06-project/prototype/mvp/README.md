# 手机冰箱库存交互预览 V2

## V0.3 增量预览
已增加首次进入的用户协议/隐私政策同意、全文往返、暂不同意与再次阅读；Android 相机申请前的应用解释弹窗，以及标注为演示控制的允许/拒绝/受限/设置返回/相册替代路径。系统权限仍是模拟。

设置最下面依次为用户协议、隐私政策、反馈，再显示「APP 备案号待登记」；不使用其他产品的备案号码。协议全文共用 `../shared/legal-content.js`，与官网同源。旧 `npm run dev` 的 4173 服务已兼容共享资源，服务需重启才能加载新 server.js；也可从统一预览服务 `http://127.0.0.1:4180/mvp/` 访问。

反馈支持保留草稿、提交中、防重复、失败重试和本地模拟回执，演示控制可切换结果与游客会话就绪状态。正式 Shared Platform 反馈已存在，但 App 游客登录公开契约尚待补齐；预览不连接平台，不创建真实账号、不发送反馈。游客会话未就绪不影响库存操作。

`privacy-flow.js` 在统一隐私同意后记录最少必要的本地白名单事件，队列最多100条，不含照片/库存编号/反馈正文/凭据，不发网络请求；不设置独立产品分析开关。隐私政策页的整体撤回会清除未发送事件、返回首进说明，保留库存；再次同意恢复模拟游客会话。`fridge-preview-v3-service` 保存这些演示状态，与原有库存 key 分离。

运行 `node validate_v3.cjs` 验证首进/权限/反馈/设置/撤回与事件门禁；运行 `node validate_preview.js` 保留原有库存主流程回归。Windows 可使用已安装 Google Chrome；`PREVIEW_PLAYWRIGHT_PACKAGE` 可指定可用 Playwright package.json，`PREVIEW_CHROME` 指定浏览器。

V0.3 仅新增本轮协议/权限/反馈/身份和埋点体验；通知 V0.2.2 完成态与正式空冰箱需求尚未因此自动完成。当前只做本地原型验证，不声明全面设计系统合规或正式设备验收。

本轮以 `01-product/mvp/MVP.md` 与 `plans/preview_epic_plan.md` 的确认范围制作。无产品名，手机优先；桌面以居中手机画布展示。原型不代表 Android/iPhone 工程、原生拍摄或系统通知已交付。

## 运行
直接打开 `index.html` 即可离线运行；或 Node 20+ 下 `npm run dev`，访问 `http://127.0.0.1:4173`。前端零第三方依赖、零外部请求，照片 sprite 为 `assets/food-photos.png`。

## 体验
- 首页：上层冷藏占满一行，下层冷冻/常温等宽等高。只保留标题、右上角设置入口和柜体，不设底部导航或指示条；真实照片圆形缩略图、编号、区域记录数、超额 +N 保留。图代表记录，不推断实际数量或占用体积。
- 点击区域：圆形照片记录；「食材入库」「整理食材」；编号和入库日期，不填写/识别食材名、数量、生产日期。
- 入库：明确示意的模拟相机，点快门立即入库并保持相机打开，可连续拍摄/切区域，「完成」返回当前拍摄区域；相册本机多选，一张一条。无真实摄像头权限请求；读取失败可重选。图片本机缩小到 512px JPEG，超过 20MB 明确提示。
- 整理：「都在、剩一半、剩少量、没了」是绝对当前状态。前三项只更新所点记录的上次整理时间，按其间隔重新安排检查，保留原入库时间；「没了」进入历史停止提醒。可撤销。
- 详情：修改入库时间/检查间隔/下次提醒/区域、替换照片（不新建记录）。移动不改间隔和提醒。检查间隔用于之后整理；指定下次时间控制本次提醒。
- 历史：从设置进入，左上返回设置；保留到主动删除；可恢复，恢复按原间隔重新安排检查。历史删除和误拍删除均需确认，提示中可撤销。
- 设置：首页右上角齿轮进入，左上返回首页。默认冷藏3天/冷冻14天/常温3天、17:30；仅影响新记录，不覆盖现有记录。
- 提醒演示：从设置进入、左上返回设置；待检查页返回对应通知页。设置底部推进模拟时间。到检查时间的记录合并一次生成 App 内通知示意，不申请浏览器通知权限，不做每日重复或3天催促。通知可直达该通知仍待检查的在库记录，并直接四状态整理。超过2天未整理且有在库记录，首页出现指定文案与「去整理」按钮；有到检查时间的食材时优先显示「放太久了，这些食材还新鲜吗？」。按钮直达跨区域全部在库记录，待检查优先；浏览、入库和改默认设置不重置最近整理时间。
- 本机存储：`fridge-mobile-preview-v2` 独立 key；localStorage 失败会保留本次内存修改、提示风险并提供重新保存，不承诺已持久保存。旧 V1 不混入。

## 验证
执行 `node validate_preview.js`。Playwright 从本地包或 Codex bundled runtime 解析；本机 Chrome 可由 `PREVIEW_CHROME` 指定，默认使用安装的 Google Chrome 或 Playwright Chromium。浏览器启动可能需要宿主许可。

脚本验证 +N、区域、连续拍摄、相册多图/失败、替图、四状态及单条更新、撤销/恢复/删除确认、移动保留时间、默认设置不覆盖、合并提醒只一次、>2天提示及浏览不更新、持久化/存储失败恢复、320/390/430无横向溢出。`.qa/v2-*.png` 为本轮截图。
