简单记下，也容易坚持

不用把生活，填成一张表。

01 / 拍下来

一张照片，一条记录。

不用填写名称和数量。选好储存区域，可以连续拍摄，也能从相册一次加入多张照片。

＋
02 / 看一看

还剩多少，你来确认。

不是反复加减数字。每次整理，只确认你看过的食材；没了就移到历史，也可以撤销。

都在剩一半剩少量没了
03 / 想起来

到了时间，提醒检查。

按食材的检查间隔提醒，处理后开启下一周期。没有处理的仍留在待检查列表。

你的食材，留在你的设备里

记录轻一点，
边界说清楚。

照片、库存和历史记录保存在本机。初版不做食材识别，不做云同步，也不要求填写账号密码。

正式版计划通过共享平台提供无感游客身份、意见反馈和必要产品分析。库存不因此上传；具体处理范围在隐私政策中说明。

卸载或清除应用数据可能丢失本机记录；检查提醒不构成食品安全结论。
