# 主路径与返回

- 首次打开 → 统一协议说明 → 用户协议/隐私政策全文 → 返回同一步 → 同意进入首页；暂不同意停在可重新阅读的说明页。
- 首页 → 区域 → 食材入库 → Android相机解释 → 继续申请 → 授权后连续拍摄；拒绝/受限 → 相册或系统设置；设置返回重新检查。
- 同意后后台建立/恢复游客身份，失败仍可离线记录；没有显式注册/密码页。
- 首页 → 设置 → 用户协议/隐私政策 → 返回设置；隐私政策撤回统一授权 → 说明后回首进，不自动删库存。
- 设置 → 反馈 → 写意见 → 提交中 → 成功回执；失败 → 保留草稿并重试；返回设置后重进仍有草稿。
- 首页 → 提醒 → 对应待检查食材 → 单条四状态整理 → 更新待处理状态；通知完善规则见MVP，原型待补。
- 官网 → 体验交互预览；官网 → 协议/政策/联系；未发布商店入口无跳转。
