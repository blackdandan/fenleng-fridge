用户已明确要求先看 Agent 提出的 preview，本轮直接制作概念预览，不将假设当作已定稿 MVP。

## 产品假设
家庭冰箱管理，桌面浏览与移动端自适应。核心路径：发现应优先食用的食材 → 查看详情 → 消耗扣减并可撤销；添加食材 → 库存可见。静态本地 Mock，零外部请求，不承诺真实通知、识别或家庭同步。

## 视觉与页面
暂定名「鲜有记」，暖奶白背景、森林绿动作色、淡杏色临期提示、细边线、克制圆角。左导航，右侧工作区；移动端底部导航。首页采用编辑式标题、优先食用条、食材库存网格，辅以本地示意的购物清单。食材使用本地 SVG/CSS/emoji，不依赖远程资源。语义 CSS 变量作为待确认的概念主题；Fenleng Project Knowledge 未连接，不能声明视觉合规。
