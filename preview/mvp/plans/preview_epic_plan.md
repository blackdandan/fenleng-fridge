# 无产品名 · 手机冰箱库存预览 V2

## 授权与边界
2026-11-12 用户确认讨论方案并要求更新 preview。仅更新本地静态交互原型，不开发 Flutter 工程、不接后端、不提交或推送。目标产品是 Android/iPhone 个人免登录 App，仅存本机。原型采用浏览器本地模拟，不承诺原生相机或系统通知已实现。

## 已确认体验
- 无产品名。简洁冰箱轮廓分冷藏、冷冻；相邻常温柜。圆形食材照片缩略图、稳定排列，新增/移除补位，区域有记录数；超过容量显示 +N。数量表示记录数，不是实际份数或占用体积。
- 点击区域直接看食材照片；主按钮「食材入库」、次按钮「整理食材」。空柜引导拍第一份。
- 当前区域作为入库默认位置；一种食材一张，连续拍摄，不填名称数量。自动编号、入库时间、默认检查间隔；相册可多选，每张一条。同一记录替换照片不生成额外库存。预览提供明确模拟拍摄和本地图片选择，不依赖真实权限弹窗。
- 整理四状态「都在、剩一半、剩少量、没了」是绝对当前状态。前三者重新安排该条记录下一次检查；没了进历史取消提醒。只更新点选项，不批量确认未点选项；可撤销。
- 冷藏3天、冷冻14天、常温3天；17:30仅合并到检查时间记录的本地通知，一次不重复。不做每天固定提醒、不做3天催促。超过2天无库存实际更新才出现App内轻提示。
- 设置默认间隔/时刻，不覆盖已入库记录。每条记录时间/间隔可修改；移动区域仅改位置，不覆盖时间。保留最初入库日期。
- 历史保留到主动删除，可恢复（恢复后重新安排检查）；误拍可直接删除。删除有确认，记录移除可撤销。
- 无产品名、无购物清单、无食材识别、无生产日期、无数量录入、无过期/食用安全结论、无账号分享云同步。

## 视觉策略
移动端优先（390/320/430），桌面为居中 App 画布。奶白与温和中性色、克制森林绿语义动作色，冷藏/冷冻/常温用轻微区域差异。真实圆形食品照片为主角；中文正文至少12-14px、触摸目标尽量44px。保持简单，避免营销标题和桌面后台式布局。Fenleng Project Knowledge 未连接，使用可替换语义变量，不声明设计系统合规。
