# 鲜有记 · 家庭冰箱管理概念预览

这是用户授权先行制作的交互概念，产品人群、品牌名、功能范围和视觉风格尚待确认，并非正式定稿 MVP。没有账号、云端同步、真实提醒或食用安全判断。日期固定为 2026-11-10。

打开 `index.html` 即可离线体验；或用 Node 20+ 执行 `npm run dev`，打开 `http://127.0.0.1:4173`。无需 npm 安装，前端没有第三方依赖或外部请求。

## 体验范围
- 我的冰箱：12 种初始食材、库存概况、临期提示、位置筛选、名称/分类搜索、日期/名称排序。
- 优先食用：未来 3 天内临期与已过期，按日期排序。
- 食材详情：数量、位置、到期日和备注；填写消耗数量并确认；操作后可撤销。
- 添加食材：名称、数量、单位、储存位置、品类、日期、备注；错误输入原生验证与内联错误提示。
- 购物清单：添加、勾选、删除；勾选不会自动入库。
- localStorage 本机保存；左侧“重置演示数据”经弹窗确认后恢复数据。

## 状态与检查
- 主页面默认、搜索无结果、库存为空、优先列表为空、购物清单为空、表单失败、添加/消耗成功、撤销、重置确认。
- 原生 dialog 处理焦点与 Escape 退出；表单和图标按钮有标签，交互可键盘触达。
- 桌面侧栏、600px 以下底部导航，320px/390px 适配；支持减少动态效果偏好。
- 静态本地演示没有网络加载、权限和登录状态，不绘制不适用的虚假状态。
- 文案明确日期模拟、记录仅存本机、到期提示不等于食用安全判断。
