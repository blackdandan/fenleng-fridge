## 查看

- 直接打开 `index.html`，支持离线 file URL。
- 统一预览服务器根目录为 `preview/`，主 Agent 启动后访问 `http://127.0.0.1:4180/website/`。
- App 交互入口 `../mvp/index.html`；官网用户协议 `/website/terms/`、隐私政策 `/website/privacy/`；App 级链接降级稿 `/website/app/`。

## 页面与状态

桌面宽工作区、手机单列；照片柜体为静态库存示意，不冒充实际用户库存。页面包括主路径、能力边界、发布状态、运营主体与联系方式、协议全文。下载为明确禁用的「敬请期待」。协议正文来自 `../shared/legal-content.js`，与 App 使用相同源；加载失败有说明及返回官网路径。无外部字体、图片请求、接口或埋点采集，不写 Cookie 或 localStorage；官网事件目录留待正式隐私告知与平台登记后启用，无独立分析开关。

运营主体和联系信息使用主 Agent 核实的组织资产；网站/APP 备案未核实，均为明确占位，未套用其他产品备案号。正式域名、AASA、包名、App Store/Android 下载及门户挂载尚待工程阶段落实。
