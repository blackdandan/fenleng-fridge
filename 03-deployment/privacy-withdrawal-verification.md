# 隐私撤回设备验证交接

源码已提供 Android Activity result、iOS WKWebView delegate 返回值、Harmony startAbilityForResult；共同进入 Flutter 二次确认。Windows 本地只编译 Android；iOS 语法检查不代表 Xcode 编译，Harmony 缺工具链未编译。阶段实测见 ../02-engineering/specs/privacy-withdrawal-evidence.md。

在每端真实设备上准备可识别的本机食材和照片，核对：

1. 未同意时可阅读两份随包正文，返回仍在同意页；无撤回入口，不发起 SDK 初始化或权限请求。
2. 同意后从设置打开隐私政策，正文尾部有撤回链接；用户协议没有。返回、系统返回或阅读器关闭均不等于撤回。
3. 点撤回，确认弹窗左右至少 16px；取消保持登录、同意和本机数据。重复打开阅读器不留下 busy 状态。
4. 确认撤回返回中国同意页，停止待触发提醒，活动平台会话清空；本机食材、照片、语言和外观保留。重启仍需同意，重新同意能看到原库存。
5. 若已经拉起微信授权，在撤回后返回授权回调，不能恢复在线会话。验证重新同意后的新登录不被旧回调清理。公网测试需本产品正式配置，不能用测试 proof 代表 Provider 成功。
6. 检查原生 pending 已落盘但后续清理中断的恢复路径：重启在开业务文件和 SDK 前恢复清理；失败显示重试页。首次写盘本身失败时当前进程阻止在线服务，但不能保证未落盘的意图在强杀后恢复；用户需重试成功。
7. iPhone/iPad 的返回、VoiceOver escape、横竖屏和深浅外观；Harmony 的系统返回、结果回调及重复打开；Android 的系统返回与 Activity 关闭。含 20 语言、RTL、大字体和小屏的按钮可达性。

不声明服务端账号注销、删除已有数据、撤销平台已受理请求、所有设备上的安全擦除或微信外部客户端的强制取消。它们与停止本机授权后的新增采集是不同能力，仍遵循当前批准范围。
