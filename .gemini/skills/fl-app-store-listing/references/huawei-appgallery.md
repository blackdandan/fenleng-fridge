先确认本次要分发 Android APK，使用 `huawei-appgallery` 市场目录；HarmonyOS 5 及以上使用另一 reference 和目录。华为个人认证通过只代表账号事实，仍需核对该账号、分类、国家/地区的实际分发权限及备案/版权主体关系。

流程：查询现有包名记录 → 创建或选择 Android 应用 → 设置语言、名称、介绍、分类、图标与截图 → 上传本次正式 APK 并确认后台解析信息 → 设置资费、地区及隐私 URL → 补版权、授权、备案和审核登录 → 运行平台检查 → 在授权范围内提交 → 保存审核状态及公开商店证据。

填写素材尺寸、张数、字数和文件上限前读取当前表单，不套用 vivo、应用宝或 HarmonyOS 数值。软著和提交名称有差异时记录实际值，再按本次华为明确规则判定；不臆造例外或扩大名称门禁。

核对无 GMS 设备上的真实登录和购买路径；有 SDK 不等于必须接入全部 HMS。按实际售卖对象、地区和渠道合同核对支付要求，不能从其他商店“无内购”或“已有支付宝”推断本市场支付合规。后台需要测试账号时先验证其可登录和权益范围。

最终 APK 记录名称、包名、versionName/versionCode、ABI、SDK、签名摘要、字节数、哈希和项目正式包/真机证据。平台检测与本地验证分开，未登录无法确认字段时标记待后台核验。按新渠道三层资料模板分别输出同市场初次和版本文件。


## 新旧控制台入口差异

2026-10-15 实测，新版 HarmonyOS 控制台可列出 Android 草稿，但进入应用信息可能提示“暂不支持应用信息”。先核验[原 AGC 的 APP与元服务](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/myApp)中的 Android 标签及既有草稿，不把单个路由不支持直接当作账号无 APK 权限，也不重复创建应用。记录两处实际结果；若表单内嵌页面持续加载，保留现场并区分页面加载问题与准入拒绝。

原 AGC 保存后可能自动转到 `hdc-console`，并继续显示已保存的 Android 信息；以应用 ID、软件包类型和当前字段确认身份，不因换域内路由就重建草稿。应用信息的“下一步”会弹出跳转确认，确认后才进入版本信息。

## Android 表单操作与回执

- 当前素材快照：直角图标216×216 PNG小于2MB；介绍截图3~5张，选择竖向后要求9:16，建议450×800，PNG/JPG/JPEG均小于2MB。按每个槽位分别上传，目视核对顺序；文件选择完成不等于全部素材上传完成。保存后刷新核验图标、截图、分类和正文均保留。
- 在版本页进入“软件包管理 → 上传 → 请从本地选取文件上传”。当前APK上限4GB；上传后核对包名、版本名/号、大小、上传时间，以及该包是否已选入当前版本。包解析成功不等于兼容、隐私或上架审核通过。
- 地区默认可能为全球200个国家及新增地区。按产品实际范围选择“特定国家或地区”，先取消全球再选择目标地区，核对计数。中国大陆产品不得无依据保留境外分发及数据出境授权。
- 免费下载与应用内会员收费是不同字段，分别如实填写。APK解析出的默认权限说明可能泛指拍照录像；按真实功能改写扫码等具体用途，并补齐表单实际要求的场景材料。
- 隐私标签按业务场景分别填写。“应用功能”的数据项不能代替“向第三方披露”；核对实际登录、支付SDK及政策。传感器列表、名称、厂商信息与原始传感器数值不同，不凭列表查询就声明采集全部运动数据。
- 纸质软著的逐页图片放“应用版权证书或代理证书”图片栏；“电子版权证书”PDF栏有独立用途，不把纸质证书PDF冒充电子版权认证。自研是否需要授权按实际权利人、发行人及平台要求判断。
- 备案主办单位如实匹配登记名称、组织类型与证件类型；与个人开发者账号不同则选择主体不一致。执行一次校验并保存“验证通过”等明确结果；当前上限5次/日，不以反复点击代替核验。该结果只证明此项校验，不等于主体授权或整体审核通过。
- 年龄分级按11组内容逐项回答，区分用户创建内容、主要用途是否社区、账号信息收集、位置服务、应用内支付及无限制网络访问；不要统一选否或套用其他市场年龄。完成“验证 → 分级结果 → 提交 → 是否仅面向儿童”后，在版本分级表中核对结果。平台可能同时显示多个地区结果，以实际分发地区为提交范围。
- 保存版本草稿后取得明确“保存成功”提示；最终提交仍须审核账号、负责人联系方式、全部必填项及当次协议要求齐备。凭据不写入上架正文或SKILL。
