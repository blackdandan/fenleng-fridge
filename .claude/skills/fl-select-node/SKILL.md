# AGY 日本节点检测

筛选能实际访问 AGY 的日本出口节点，而不是只看 Clash 延迟。使用本机脚本：

```sh
python3 ~/.codex/skills/fl-select-node/scripts/refresh.py
```

## 输入

- Clash for Windows 当前已加载的订阅和 `Proxy` 组。
- 可选的完整节点名、快速筛选、裁剪配置或冷启动 Antigravity 请求。
- 裁剪配置和冷启动桌面端分别需要用户明确授权。

## 输出

- 通过两次 AGY 响应和精确 Clash 路由链验证的节点列表与最终选择。
- 活动订阅中的 `AGY可用节点1`、`AGY可用节点2` 等稳定别名。
- 每次配置写入对应的备份路径；失败时给出不含凭据的原因。

## 执行步骤

1. 让 Clash for Windows 先完成订阅更新并加载该订阅。
2. 脚本从正在运行的 Clash 控制器读取日本候选节点；每次切换后连续确认两次实际选择，再逐条启动两个独立的 `agy -p 'Reply only with: OK'` 进程。测试进程通过独立设置的代理环境强制进入 Clash 本机端口，不依赖系统代理或 TUN 恰好接管。
3. 每次请求必须同时返回 `OK`，并把该 `agy` 进程的 TCP 源端口与 Clash `/connections` 中的 AGY API 连接对应；只有连接路由链同时包含本次候选节点和 `Proxy` 才通过。旧桌面连接、其他进程的成功请求以及仅有 `Proxy.now` 一致都不构成证据。仅将两次请求都取得“响应 + 精确路由链”证据的最快节点设为当前选择，并再次确认最终选择。
4. 脚本会在实际订阅文件中为全部通过验证的节点创建/更新 `AGY可用节点1`、`AGY可用节点2` 等同配置别名，并按延迟升序放到主 `Proxy` 组首位；原始订阅节点保留，便于下次更新后继续识别。重新加载配置后这些别名生效。
5. 每次成功筛选后，脚本幂等恢复公司网络模板：公司浏览器 HTTP 代理、`myhexin`/`10jqka` 等域名的内网 DNS 策略、Wi-Fi 与 GitLab Hosts 映射，以及公司域名、私网 CIDR 的直连规则。模板规则始终置顶且不会重复。
6. 脚本会先保存当前选择；没有候选通过时，恢复它并以失败退出。

默认完整验证所有当前已加载的日本节点；可用 `--fast` 只验证延迟最快的 8 条。单次 AGY 请求默认最多 20 秒，可用 `--request-timeout SECONDS` 在 5–45 秒内调整。运行期间会临时切换节点，因此应先提示用户可能影响正在进行的代理连接。

排查单一节点时可附加 `--node '完整节点名'`，避免无关节点的超时延长检测。

默认结果只证明全新 AGY CLI 请求经过记录的节点；已经打开的 Antigravity 桌面端可能继续使用切换前建立的长连接。不要据此声称现有桌面会话已经切换。

如需排除 Antigravity 客户端复用旧连接，用户明确同意中断当前会话后可附加 `--restart-antigravity`。它会终止并冷启动桌面端，同时要求语言服务器初始化成功且其 AGY API 连接路由链命中最终节点；这仍不能替代一次实际桌面消息。要声明“桌面端消息已验证”，仍须在新会话发送一条短消息并得到回复。

## 配置裁剪

只有当用户明确要求“仅保留日本节点”或“裁剪配置”时，附加 `--prune`：

```sh
python3 ~/.codex/skills/fl-select-node/scripts/refresh.py --prune
```

裁剪前必须创建同目录、带时间戳的 `.bak` 备份。根据 Clash for Windows 的 `profiles/list.yml` 解析活动订阅文件并确认它定义了最终节点；清单不可用且有多个匹配文件时必须失败，不得按修改时间猜测。仅移除非日本代理及其策略组引用，保留策略组、规则与 `DIRECT`/`REJECT` 等特殊项。写入前后必须验证 DNS、端口、TUN、规则、订阅地址等非节点配置的语义一致；不一致则不覆盖原文件。YAML 的注释和排版可能被规范化，但运行配置不会被有意修改。订阅下一次更新可能重新写入全部节点，因此需要在每次更新后重新运行。

## 成功标准

- 每个通过节点的两次 AGY 请求都有本进程源端口和目标节点路由链证据。
- 最终节点已再次确认成为 `Proxy` 当前选择。
- 别名和可选裁剪只写入 CFW 活动订阅，所有写入均有备份。
- 默认结果只声明 CLI 验证；桌面端声明与实际完成的冷启动或消息验证一致。

## 失败处理

- 没有候选通过时恢复测试前选择并以失败退出。
- 无法取得进程级路由证据、活动订阅不唯一或配置语义校验失败时停止写入。
- 未经明确授权不得裁剪配置或重启 Antigravity。
- 不得把 Clash 控制器密钥、订阅凭据或 AGY 登录令牌打印到输出或回复中。
