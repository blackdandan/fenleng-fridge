# 申请填报信息摘要规范

本规范对应 `assets/software-copyright/application-info-summary.md.template`。摘要是官方系统填报前的事实核对源，最终交付格式固定为 `deliverables/vN/申请填报信息摘要.md`，不生成 DOCX 或 PDF。

## 字段

| 字段 | 约束 | 说明 |
| :--- | :--- | :--- |
| 软件名称 | 必填；建议采用有辨识度的 `XXXXApp` 形式 | 版本号单独填写；不得由 AI 擅自改写用户确认名称 |
| 版本号 | 必填；默认模板值 `V1.0` | 应与其他材料和官方系统一致 |
| 开发的硬件环境 | 去除空白后不超过 50 字 | 必须是用户确认的真实环境 |
| 运行的硬件环境 | 去除空白后不超过 50 字 | 必须是用户确认的真实环境 |
| 开发该软件的操作系统 | 去除空白后不超过 50 字 | 必须是用户确认的真实环境 |
| 软件开发环境 / 开发工具 | 去除空白后不超过 50 字 | 必须是用户确认的真实工具链 |
| 该软件的运行平台 / 操作系统 | 去除空白后不超过 50 字 | 必须是用户确认的真实平台 |
| 软件运行支撑环境 / 支持软件 | 去除空白后不超过 50 字 | 必须是用户确认的真实支持环境 |
| 源程序量 | 必须为正整数行数 | 应与源码提取报告和最终材料一致 |
| 开发目的 | 去除空白后不超过 50 字 | 说明真实开发目的，不写泛化营销口号 |
| 面向领域 / 行业 | 去除空白后不超过 50 字 | 使用真实行业或应用领域 |
| 软件的主要功能 | 去除空白后 500–1300 字 | 描述真实功能、用户流程和结果；不得虚构功能 |
| 软件的技术特点 | 去除空白后不超过 100 字 | 描述真实技术表达，不承诺审查结论 |

## 校验方式

运行：

```bash
python scripts/validate_application_info.py \
  --input work/申请填报信息摘要.md \
  --report work/申请填报信息摘要审计报告.json
```

脚本会检查字段完整性、占位符、版本格式、源程序量整数格式和上述字数范围。任何失败都属于阻断项，不得复制到 `deliverables/vN/`。
