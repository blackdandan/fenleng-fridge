# Software Copyright Boundary Rule

## 适用场景

当任务涉及软件著作权申请、材料准备、软件说明书、源程序鉴别材料、自检审查或补正说明时，必须遵守本规则。

## 约束对象

- Skill
- Skill
- Agent
- Script
- Template
- Schema
- 用户交付材料

## 核心约束

1. 本 Skill 只处理软件著作权申请与补正，不处理商标、专利、诉讼、侵权结论或许可谈判。
2. AI 可以辅助整理材料、发现风险、生成草稿和执行自检，但不得声称替代律师、代理机构或主管机构审查。
3. 涉及当前官方提交入口、材料格式、审查期限和填报要求时，必须核验中国版权保护中心或其他权威来源的最新要求。
4. 软件名称、简称、版本号、申请主体、开发方式等事实信息必须来自用户确认或已有材料，不得猜测补全为最终事实。
5. 所有交付件必须标记需要人工签字、盖章、上传、复核或官方系统填写的事项。
6. 首次申请材料计划默认包含软件独立开发及原创性声明；如存在开源代码、第三方代码或委托/合作开发，必须生成对应说明并交由用户确认。
7. 不得默认生成“AI 辅助说明”或把 AI 相关说明列入通用提交材料。只有在用户明确要求、补正通知明确要求或最新官方口径明确要求时，才能作为人工确认项另行处理。
8. 补正阶段不得把声明函作为事后补救的唯一动作；必须先检查首次申请材料中是否已有声明，再根据补正通知生成补正说明或更新版声明。
9. Skill 终点不是 Markdown 草稿，而是当前轮次的最终材料包。可编辑 Word、扫描报告、补正说明、第三方/开源说明和自检报告必须放入 `work/`；最终 PDF、申请填报 Markdown、清单和用户执行步骤必须放入 `deliverables/vN/`。
10. 被审计为 high_risk 的源程序鉴别材料可以以 `源代码.pdf` 形式保留在当前 `deliverables/vN/` 供人工复核，但不得标记为可提交；源程序 Word 和审计报告必须保留在 `work/`，并触发重新选材或人工确认。
11. Skill 只能在等待用户补齐阻断输入或最终材料包生成完成时停止。不得在草稿、过程文件、风险提示或 Markdown 材料生成后停止。
12. 截图、主体证明、签字盖章、官方系统填报、补正通知原文和事实性承诺属于用户动作；缺失时必须向用户明确索取，并列出所需文件、格式和用途。截图缺失时，优先生成带截图占位的 Word 说明书，并告知用户在对应占位处插入截图；只有截图缺失导致无法形成说明书主体内容时才作为阻断输入暂停。
13. 最终材料包必须包含用户执行步骤文档，逐步列明用户需要确认的软件名称、版本、申请主体、开发事实、图标规格、截图补充、签字盖章、官方系统填报和最终提交材料。
14. Word 转 PDF 必须使用可嵌入中文字体的渲染器，并对生成 PDF 做 PNG 视觉检查；仅依赖本机字体替换、导致 PDF 内无中文字体资源的转换结果不得进入交付目录。

## 责任边界

| 类型 | 可以做什么 | 不可以做什么 |
| :--- | :--- | :--- |
| 用户 | 提供和确认软件名称、版本、申请主体、开发方式、开源/第三方情况、最终提交材料 | 把未确认事实交给 AI 代为承诺 |
| AI | 整理材料、归纳功能、提示风险、起草说明书和声明函、诊断补正原因 | 确认事实、承诺法律结论、虚构开发事实 |
| Script | 遍历源码、提取材料、生成 DOCX/PDF、修复 DOCX、审计重复率/截断/残留/页数、打包最终材料 | 判断原创性、决定最终提交、替用户签署声明 |

## 禁止事项

- 不得虚构申请主体、开发完成日期、发表状态或开发方式。
- 不得承诺一定通过审查。
- 不得将历史样例材料当作通用事实直接套用。
- 不得输出规避审查、伪造原创性或隐瞒第三方代码来源的建议。

## 验收要求

- 输出中明确区分“已确认事实”“模型整理内容”“需要人工核验事项”。
- 材料清单能覆盖首次申请和补正申请两种模式。
- 最终输出必须区分过程文件目录和当前轮次最终交付目录。
- 当前轮次最终交付目录必须是 `deliverables/vN/`，并包含最终 PDF、申请填报 Markdown 和清单；只有 Markdown 草稿不能视为完成。历史 `vN/` 目录不得被新一轮补正覆盖。
- PDF 文件应能在无本机中文字体的环境中显示中文；检查字体资源、页眉、正文和截图后再标记为可复核。
- 源代码鉴别材料的页码必须位于页面顶部居中且只显示纯数字，软件名称位于页眉左侧；不得使用右下角页码布局。
- 源代码交付 PDF 必须恰好 60 页（渲染后 3420 行真实源码）；统一排版为英文/数字 Courier New 9 磅、中文字符同字号嵌入式中文回退字体、固定行高 12.24 磅、每页 57 行、95 字符换行，且源代码中不得出现 `import` 语句或空白行，并由脚本自动校验页数、空白行和禁止项。
- 未完成时必须说明具体阻断输入，不能只给出草稿和泛化建议。
- 软件说明书缺截图时，最终交付清单必须列出 Word 文档中的截图占位和用户补图动作。
- 最终交付目录必须包含用户执行步骤文档，不能只提供材料清单。
- 首次申请清单包含独立开发及原创性声明，并明确是否需要第三方/开源情况说明。
- 对官方规则不确定的内容必须标记为需核验。
