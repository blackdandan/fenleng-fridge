# 流程优化候选

状态：阶段建议，未改基座规则。依据见[audit.md](audit.md)与[evidence.md](evidence.md)。

1. 区分当前交付状态与历史过程，用一份当前交付索引关联源码、APK、官网与小程序manifest，减少旧文档误导。
2. 对固定工具链维护非交互消费者入口；固定FVM配置、包内SDK和Windows路径兼容应在首份源归档时验证。
3. 源码冻结后统一归档；仅交接文字变化时按源文件哈希保留已验证范围，不因日期或叙述更新无条件重复全部设备矩阵。
4. 设备安装等待应绑定可取消进程，先验证boot完成和package服务，再执行安装。

以上候选不能删除签名、真实平台回执、隐私时序、正式设备或实际构建检查。没有完整趋势数据，暂不提出跨Epic路由统计结论；基座技能变更如需实施另行评审。
