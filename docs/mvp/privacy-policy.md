## 2. 处理范围与目的
| 场景 | 信息与用途 | 处理位置 |
|---|---|---|
| 拍照与相册入库 | 主动拍摄/选中的照片、记录编号、储存区域、入库和整理时间、剩余状态，用于展示和管理库存 | 本机，不上传食材照片或库存正文 |
| 检查提醒 | 检查间隔、提醒时间及处理状态，用于本地通知与 App 内待检查列表 | 本机 |
| 无账号密码使用 | 由共享平台生成本应用的游客标识、会话凭据与必要会话状态，支持无账号密码使用、反馈和必要产品分析 | 设备与共享平台 |
| 意见反馈 | 你主动填写的意见、应用版本、项目归属、提交标识及必要故障关联信息，用于受理和排障 | Shared Platform；初版不要求截图、日志、联系方式附件 |
| 产品分析 | 经白名单约束的页面/动作/结果事件、时间、平台、版本、构建号、渠道、语言与必要会话上下文，用于功能使用、漏斗和失败率分析 | 正式端通过官方 SDK 发送至共享平台 |
| 网络服务运行 | 网络请求所需的 IP 等网络信息可能由服务基础设施处理，用于传输和故障排查；具体日志项与保留期正式接入时核定 | 共享服务基础设施 |

不收集通讯录、定位、麦克风、广告标识或硬件唯一标识；不把照片、食材内容、记录编号、反馈正文、个人联系方式或凭据放进分析事件。不进行食材识别、广告画像或模型训练。

## 3. 同意与系统权限
首次使用前展示本政策和用户协议，选择同意后才启动联网身份和必要产品分析。尚未同意时不启动相关采集，不申请相机或通知权限。

Android 在你触发拍摄、相机尚未授权时，先显示应用的相机用途解释，再由你选择是否继续申请系统权限；照片仅用于本机库存，不录音。拒绝可改用相册，无法再次申请时可主动前往系统设置。相册优先使用系统图片选择器，仅读取你选中的图片。系统通知仅在你选择开启时申请，拒绝后保留 App 内检查入口与库存功能。系统授权可随时在设备设置调整。

## 4. 共享服务与第三方
Fenleng Shared Platform 与 Fenleng Client SDK 为同一运营体系下的共享能力，不代表食材数据云同步。初版不接广告、支付或社交登录 SDK。实际 SDK 名称、版本、数据项及服务部署信息在正式接入时维护于数据处理说明；新增第三方接收方或处理目的时先更新告知并按适用要求取得授权，不以本稿授权任意未来处理。

## 5. 保存与删除
本机照片、库存和历史保留至你主动删除或清除应用数据；卸载可能导致永久丢失。原型浏览器存储不等同原生应用的持久性保证。

拟定服务端保存策略：反馈正文与受理记录在处理完成后最长保留180天；原始产品分析事件最长保留90天，之后删除或转为无法识别个人的汇总数据；会话按平台有效期与撤回状态管理。上述为本产品接入要求，正式发布前须核实平台配置已落实；如依法需延长，说明范围与依据。初版不上传附件；平台现有附件摘要30天失效规则不等于反馈正文自动删除。

## 6. 你的权利
你可在应用中查看、更正或删除本机记录，在系统设置调整权限，在设置的隐私政策页发起撤回统一隐私授权。撤回后停止联网身份服务及分析、清空未发送事件，返回首进说明；本机库存不会自动删除。服务端数据的查阅、复制、更正、删除及撤回请求，可通过反馈或上述邮箱/电话联系；我们在15个工作日内答复或说明进展，必要时仅核验与请求匹配的最少信息。

## 7. 安全、未成年人和更新
我们采取与处理活动相适应的保护措施，凭据不进入分析事件；不承诺任何系统绝对无风险。如发生涉及你的个人信息安全事件，按适用要求处理与告知。

本产品面向具有相应理解能力的个人用户，不专门面向不满14周岁儿童。监护人发现相关问题可联系我们处理。重大目的、方式或信息种类变更会重新提示；政策始终可从设置和官网访问。

## 8. 本地预览
当前预览中的游客身份、反馈回执和分析记录均为本地模拟，不向 Shared Platform 或其他服务发送；不会真实申请 Android 权限或发送系统通知。正式上线前须按真实实现更新政策与生效日期。
