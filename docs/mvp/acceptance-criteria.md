# 产品验收清单

权威范围 `MVP.md` V0.3。测试通过与用户最终认可分别记录。

| 场景 | 可观察通过条件 |
|---|---|
| 首次进入 | 先显示统一协议说明，两份全文可读；暂不同意不绕过；同意后进入；再开不重复；版本与时间可记录 |
| 协议返回 | 首进读完返回首进；设置读完返回设置；官网可直接打开正文；三入口同版本 |
| 拍摄解释 | 未授权Android触发拍摄先解释；继续后模拟授权；取消可返回，相册可替代；已授权不重复；拒绝/受限可恢复 |
| 无感身份 | 无账号密码页；身份服务失败不阻断库存；反馈可重试；不将本地模拟当成平台登录 |
| 反馈 | 必填校验、提交中防重复、失败保留草稿、重试、成功有模拟回执、返回不丢草稿 |
| 设置底部 | 协议、政策、反馈在功能内容之后，备案最下方、可读、未核实不冒用号码 |
| 产品分析 | 统一同意前零事件、无独立分析开关、仅事件目录允许的枚举属性、不含照片/正文/编号、撤回清空 |
| 官网 | 手机与桌面可读；体验入口、协议、联系方式可达；未发布渠道不可下载；无虚构用户量或线上接入声明 |
| 首次空冰箱 | 规则已定义，当前库存示例保留；单独待实现/验收，不计作本轮通过 |
| 通知闭环 | V0.2.2规则已定义，原型待补；不可因旧验证通过而宣称已通过 |

交互预览的拍摄、身份和通知模拟符合原型定位，不作为原型不完善的理由。正式工程的原生权限、系统送达、平台联调与发布另验收。
