请阅读本协议及隐私政策。首次使用时主动选择「同意并继续」后进入服务；如暂不同意，可返回阅读或停止使用。涉及系统权限时另由你主动授权。

## 2. 服务范围
你可拍摄或选取照片建立食材记录，按冷藏、冷冻、常温管理，整理剩余状态、查看历史并安排本地检查提醒。不要求填写账号密码，拟通过共享平台建立应用隔离的游客身份。游客身份不提供换机恢复或跨设备库存同步。

检查时间是自行确认食材状态的提示，不是保质期或食用安全判断。请结合实际保存条件、包装标识及食材状况判断；应用不提供医疗、营养或食品安全鉴定。系统权限、系统省电策略或设备状态可能影响提醒送达，可在应用内主动检查库存。

## 3. 数据与设备
食材照片、库存及历史保存在本机；卸载、清除应用数据或设备故障可能导致丢失，目前不提供云端备份。你可修改、移出、恢复或删除记录。删除和重置操作将明确说明影响，不以游客会话恢复承诺找回本机数据。

游客会话、反馈与最少必要产品分析使用联网共享服务，处理方式见隐私政策。请勿在意见中提交密码、身份证件、支付信息等无关敏感资料。原型内的拍摄、身份、通知及反馈为本地模拟，不代表真实提交、通知发送或安装包交付。

## 4. 使用规则与权利
你保留自行拍摄或合法使用的图片及内容的权利。请勿提交违法、侵权或危害服务正常运行的内容。本应用不因你使用本地照片而获得将照片公开、售卖或用于模型训练的许可。

应用软件、界面及运营方提供内容的相关权利归其合法权利人所有。法律允许范围内的正常使用不受本条限制。

## 5. 服务调整与责任
版本更新、维护或外部系统变化可能影响部分功能，我们会对重大调整作出适当说明。因应用自身问题造成的责任按适用法律承担，本协议不排除或限制依法应承担的责任及消费者法定权利。暂不含付费、广告、分享或云同步；如新增，将更新规则并完成相应告知。

## 6. 终止、争议与联系
你可停止使用、在隐私政策页撤回统一隐私授权，或按需删除本机数据。撤回不自动删除本机库存，也不影响撤回前依法进行的处理；涉及服务端信息的查阅、更正、删除等请求可通过反馈或上述联系方式提出。

重大规则变化会重新提示，不将继续浏览视为重新同意。本协议适用中华人民共和国法律；争议优先协商，协商不成可依法向有管辖权的人民法院提起诉讼。
