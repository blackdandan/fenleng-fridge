# 04-operations

## 用途

保存账号、合规、上架、知识产权和项目管理增强资料。

## 放什么

- accounts.md
- compliance.md
- app-store.md
- project-management.md
- 迁移产生的合规或知识产权资料子目录

## 不放什么

- 不放真实代码
- 不放工程架构指导
- 不放当前产品需求源文档

## 关键文件

- README.md
- accounts.md

- app-store.md

- [Owner待办](owner-follow-ups.md)：正式身份、部署和设备接续事项。
- [被委托的实现决定](implementation-decisions.md)：授权来源与实际工程选择。
- [阶段效率审计](../docs/ai-coding-audits/fridge-full-implementation/audit.md)：保持snapshot直至Epic完成验收。
